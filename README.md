# Windows 开机启动管理器 功能说明

## 1. 程序概述

Windows 开机启动管理器是一个基于 Python 与 Tkinter 的图形化工具，用于集中查看、定位、删除和添加 Windows 开机启动项。程序可以扫描当前用户与所有用户的启动文件夹、当前用户与本地计算机的注册表 Run / RunOnce 项，以及 Windows 自动启动服务，并在统一界面中展示。

程序支持解析带空格、带参数的启动命令，支持解析快捷方式，支持提取启动项图标，支持双击定位真实文件，支持拖放 `.exe` / `.lnk` 文件添加到当前用户启动文件夹。

---

## 2. 运行环境

- 操作系统：Windows
- Python：Python 3
- 图形界面：Tkinter
- 第三方依赖：
  - pywin32
  - pillow
  - tkinterdnd2

### 2.1 安装依赖

```bash
pip install pywin32 pillow tkinterdnd2
```

### 2.2 启动方式

```bash
python 脚本文件名.py
```

也可以使用 `pythonw` 启动，以减少控制台窗口显示。

## 3. 主要功能

### 3.1 扫描启动文件夹

程序会扫描以下启动文件夹：

| 来源 | 路径 | 可删除性 |
|---|---|---|
| 当前用户启动文件夹 | `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup` | 可删除其中的 `.lnk` 快捷方式 |
| 所有用户启动文件夹 | `%PROGRAMDATA%\Microsoft\Windows\Start Menu\Programs\Startup` | 只读显示，默认不可直接删除 |

当前用户启动文件夹不存在时，程序会自动创建。

程序只扫描启动文件夹中的 `.lnk` 快捷方式，并解析其目标程序、参数、工作目录和图标位置。

### 3.2 扫描注册表启动项

程序会扫描以下注册表位置：

| 来源 | 注册表位置 | 可删除性 |
|---|---|---|
| HKCU Run | `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` | 可删除 |
| HKLM Run | `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run` | 只读显示 |
| HKCU RunOnce | `HKCU\Software\Microsoft\Windows\CurrentVersion\RunOnce` | 可删除 |
| HKLM RunOnce | `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\RunOnce` | 只读显示 |

对于可删除的当前用户注册表项，程序可以删除对应注册表值。对于 HKLM 项，程序只显示，不直接删除。

### 3.3 扫描自动启动服务

程序会枚举 Windows 服务，并筛选启动类型为自动启动的服务：

- 服务启动类型：`SERVICE_AUTO_START`
- 来源显示：`系统服务（自动启动）`
- 服务项默认只读，不提供直接删除操作

程序会尝试从服务的二进制路径中提取可执行文件路径和参数，便于双击定位。

### 3.4 启动命令解析

程序支持解析多种 Windows 启动命令格式，例如：

```text
"C:\Program Files\App\App.exe" /startup
C:\Program Files\App\App.exe /startup
%ProgramFiles%\App\App.exe /startup
C:\App\App.exe
App.exe /startup
```

解析功能包括：

- 展开环境变量
- 处理带引号路径
- 处理不带引号但包含空格的路径
- 提取第一个 `.exe` 路径
- 区分可执行文件路径与启动参数
- 在 PATH 环境变量中查找可执行文件

### 3.5 快捷方式解析

对于 `.lnk` 快捷方式，程序使用 `WScript.Shell` 解析以下信息：

- 目标程序路径
- 启动参数
- 工作目录
- 图标位置

这些信息用于界面显示、图标提取、双击定位和启动项添加。

### 3.6 图标提取

程序支持从以下文件提取图标：

- `.exe`
- `.dll`
- `.ico`
- `.lnk` 快捷方式

图标提取逻辑：

- 优先使用快捷方式指定的图标位置
- 其次使用快捷方式目标程序图标
- 最后尝试快捷方式本身
- 对启动命令则先解析出 EXE，再提取图标
- 图标尺寸为 16x16
- 提取后的图标会缓存，避免重复提取
- 使用 Pillow 与 `ImageTk` 显示在 Tkinter 界面中

如果图标提取失败，不影响启动项列表显示。

### 3.7 图形界面展示

主界面使用 Tkinter Treeview 展示启动项，列为：

| 列 | 说明 |
|---|---|
| 图标 | 启动项图标 |
| 软件名 | 启动项显示名称 |
| 来源 | 启动项来源，如当前用户启动文件夹、HKCU Run、系统服务等 |
| 启动位置 | 启动命令、目标路径或服务路径 |

界面包含：

- 顶部标题
- 状态栏
- 启动项列表
- 垂直滚动条
- 水平滚动条
- 底部功能按钮

状态栏会显示启动项总数，并提示可以拖放 `.exe` 或 `.lnk` 文件添加开机启动。

### 3.8 双击定位

双击列表中的启动项时，程序会根据来源执行不同操作：

| 启动项类型 | 双击行为 |
|---|---|
| 当前用户启动文件夹 | 在资源管理器中选中对应快捷方式 |
| 所有用户启动文件夹 | 在资源管理器中选中对应快捷方式 |
| HKCU / HKLM 注册表项 | 尝试定位真实 EXE，并在资源管理器中选中；失败时询问是否打开注册表编辑器 |
| 系统服务 | 尝试定位服务对应的 EXE；失败时询问是否打开服务管理器 |
| 无法定位 | 弹出提示信息 |

程序使用 `explorer.exe /select,` 在资源管理器中定位文件。

### 3.9 删除启动项

选中启动项后，可以点击“取消开机启动（选中项）”按钮删除。

删除规则：

| 来源 | 是否可直接删除 |
|---|---|
| 当前用户启动文件夹 `.lnk` | 可以 |
| HKCU Run | 可以 |
| HKCU RunOnce | 可以 |
| HKLM Run | 不可直接删除，只读显示 |
| HKLM RunOnce | 不可直接删除，只读显示 |
| 所有用户启动文件夹 | 不可直接删除，只读显示 |
| 系统服务 | 不可直接删除，只读显示 |

删除前会弹出确认对话框。删除失败时会记录错误日志并提示用户。

### 3.10 拖放添加启动项

程序支持将 `.exe` 或 `.lnk` 文件拖放到窗口中，以添加到当前用户启动文件夹。

添加逻辑：

- 仅接受 `.exe` 和 `.lnk` 文件
- 在当前用户启动文件夹中创建 `.lnk` 快捷方式
- 如果目标 EXE，则设置工作目录为 EXE 所在目录
- 如果存在同名快捷方式，自动追加 `_1`、`_2` 等序号
- 添加成功后刷新列表并弹出提示

拖放解析使用 `tkinterdnd2` 的 `splitlist`，可以处理包含空格的路径。

### 3.11 打开启动文件夹

界面提供“打开启动文件夹”按钮，可以一键打开当前用户启动文件夹：

```text
%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup
```

### 3.12 刷新列表

界面提供“刷新列表”按钮，可以重新扫描所有启动项来源，并更新列表显示。

### 3.13 错误日志

程序会将异常信息写入脚本所在目录下的 `error.log` 文件。

日志内容包括：

- 快捷方式解析失败
- 图标提取失败
- 注册表删除失败
- 服务扫描失败
- 添加启动项失败
- 双击定位失败
- 删除启动项失败
- 程序启动失败

如果主程序启动失败，会尝试弹出错误提示框，并提示查看 `error.log`。

程序扫描的启动项来源包括：

2. 所有用户启动文件夹

4. HKLM Run
5. HKCU RunOnce
6. HKLM RunOnce
7. Windows 自动启动服务

---

## 6. 权限说明

- 当前用户启动文件夹中的快捷方式通常可以直接删除。
- HKCU Run 与 HKCU RunOnce 通常可以直接删除。
- HKLM Run、HKLM RunOnce、所有用户启动文件夹、系统服务默认只读显示。
- 删除系统级启动项通常需要管理员权限，建议使用系统工具或注册表编辑器手动处理。
- 程序不会直接修改 HKLM、所有用户启动文件夹或系统服务。

---

## 7. 使用步骤

1. 安装依赖：

   ```bash
   pip install pywin32 pillow tkinterdnd2
   ```

2. 运行程序：

   ```bash
   python 脚本文件名.py
   ```

3. 查看启动项列表。
4. 双击启动项可定位真实文件或打开相关系统工具。
5. 选中可删除项后，点击“取消开机启动（选中项）”进行删除。
6. 将 `.exe` 或 `.lnk` 文件拖入窗口，可添加到当前用户启动文件夹。
7. 点击“打开启动文件夹”可直接打开当前用户启动目录。
8. 点击“刷新列表”可重新扫描启动项。

---

## 8. 注意事项

- 本程序仅适用于 Windows。
- 需要安装 `pywin32`、`pillow`、`tkinterdnd2`。
- 系统服务、HKLM 注册表项、所有用户启动文件夹默认只读。
- 删除启动项前请确认目标，删除操作不可撤销。
- 图标提取失败不会影响启动项扫描和显示。
- 拖放添加仅支持 `.exe` 和 `.lnk` 文件。
- 如果程序异常，请查看脚本目录下的 `error.log`。
